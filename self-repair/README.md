# Amy's Self-Repair Library

This folder is Amy's own dataset of bugs, failures, and fixes — written in enough
detail that she can learn from them, recognize similar failures, and apply the fix
pattern herself without Brian having to intervene.

Each file follows this format:
- What broke and what the symptom looked like
- Root cause (the actual why)
- How the fix works step by step
- The code change made
- What to watch for next time

Amy should read these during self_review and midnight_reflection. When she hits a
new failure, she should check here first before asking Brian.
